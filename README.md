# Figure Coaching Landing Page

A static landing page for the Figure Coaching business, built with HTML, CSS, and JavaScript.

## Features

- One-page responsive layout with four main sections: HERO, CREDO, ME, ABOUT COACHING
- Smooth scrolling and subtle reveal animations
- Clean visual identity with warm pine green, beige accents, and optional gold highlights
- Placeholder content ready for your own messaging

## Local Preview

Open `index.html` in your browser, or use a local development server such as:

```bash
cd /Users/rekaehreth/Documents/repos/figurecoaching
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
