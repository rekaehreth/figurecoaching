Plan: Coaching Business Landing Page

TL;DR — Build a static HTML/CSS/JavaScript landing page with 4 sections (HERO, CREDO, ME, ABOUT COACHING) deployed to GitHub Pages with your custom domain. Design uses warm pine green + beige + optional gold, mobile-responsive, with smooth scrolling and light animations.

## Steps

Phase 1: Project Setup
1. Create GitHub repository `coaching-landing-page` under your account (rekaehreth)
2. Initialize repo with `index.html`, `css/styles.css`, `js/main.js`, `.gitignore`, `README.md`

Phase 2: HTML Structure
3. Build semantic HTML with enhanced context:
   - HERO: Mirror client's journey (headline speaks to the "figuring it out" energy)
   - CREDO: Your beliefs + subtle mention of the 4 pillars (not central, integrated into narrative)
   - ME: Your figure skating background + philosophy ("I meet you where you are—through different explanations and approaches") + photo placeholder
   - ABOUT COACHING: What coaching solves + benefits + booking CTA
4. Add sticky navigation with smooth-scroll links
5. Footer with contact/social

Phase 3: Design & Visual Identity
6. Responsive CSS with color palette:
   - Primary: Warm pine green (#4a7c59)
   - Accents: Neutral beige (#e8dcc8)
   - Secondary: Gold (#d4af37)
7. Gestalt-inspired circle design element (use as visual accent—header, section dividers, or background pattern)
8. Create 4 icons/symbols for subtle placement (e.g., CREDO section):
   - Gestalt figure-ground circle
   - Figure skating silhouette
   - Lightbulb or "aha" moment (figuring it out)
   - Magnifying glass or target (visualization)
9. Mobile-first responsive layout with calm whitespace

Phase 4: Interactivity
10. Smooth scrolling on nav links
11. Subtle animations (fade-in on scroll, hover effects on buttons/icons)
12. Booking button → Proton booking link

Phase 5: Deployment
13. Enable GitHub Pages + custom domain via `CNAME` file
14. Configure DNS records

Phase 6: Testing
15. Cross-browser & mobile testing
16. Verify all links work
